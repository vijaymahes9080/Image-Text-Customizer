How to use Image Text Customizer

1. Upload Image: Drag and drop any image or pick one of the sample posters to test instantly.

2. OCR Text Detection: Text regions are detected automatically in English, Tamil, or both. You can also re-run detection anytime from the toolbar.

3. Edit & Customize: Click any detected text box to select it. The tool erases the original text and restores the background seamlessly while letting you type replacement text.

4. Transform: Drag to move, grab corner handles to resize, and use the top handle to rotate text.

5. Keyboard Shortcuts:

  • V: Select Tool
  • T: Add Custom Text
  • H / Space+Drag: Pan Canvas
  • Ctrl + Z: Undo
  • Ctrl + Y / Ctrl+Shift+Z: Redo
  • Delete / Backspace: Delete Selected Text

6. Full Resolution Export: When downloading, your edits are rendered against the full original resolution of your image!
